# Состояние работ и следующие шаги

Обновлено: 2026-10-28, сессия сборки/живого запуска.

## Что проверено живьём на этой машине

- Сборка: `cargo build --release` (Rust 1.99.1 + MSVC 14.44) и `packaging/build-app.ps1` проходят;
  NSIS-установщик **86.75 MiB** (`app/src-tauri/target/release/bundle/nsis/VoiceRunaCore_0.1.0_x64-setup.exe`).
- Установка: silent `/S`, per-user в `%LOCALAPPDATA%\VoiceRunaCore` (`voiceruna.exe` 3.7 МБ + `sidecar\` 316.6 МБ), ~34 с.
- Запуск: окно VoiceRunaCore 476×679 (клиент 460×640), статус «на связи», история, поле ввода, тумблер модели.
- Сайдкар: слушает только `127.0.0.1`, `/health` без токена, остальное — 401 без `X-Vox-Token`.
- Single instance: второй запуск завершается, остаётся один процесс.
- Автозапуск: запись `HKCU\...\Run\VoiceRunaCore = ...voiceruna.exe --hidden`, старт скрытым.
- Первый запуск: скачаны whisper-small (461 МБ) и Silero VAD (2.2 МБ); токен, конфиг и `apps.json` созданы в `%APPDATA%\VoiceRunaCore`.
- Команда из окна: текст → `POST /command` → история («Вы»/VoiceRunaCore) + ответ; без ключей LLM приходит «нет связи» (как в §15).
- Холодный старт: окно ~0.15 с, сайдкар health ~1.6 с; RAM: приложение 26 МБ, сайдкар 112–113 МБ.

## Что осталось сделать в следующей сессии (≈10 минут)

1. Пересобрать установщик с уже готовым фиксом «залипшего» скачивания
   (код в `sidecar/voiceruna/voice/download.py`, тесты `tests/test_download_stall.py`):
   ```powershell
   # из окружения с Rust/MSVC:
   powershell -File packaging\build-sidecar.ps1 -Clean
   powershell -File packaging\build-app.ps1 -SkipFrontend
   # затем silent install и один запуск
   ```
2. Проверить на живой сети, что при недоступном зеркале vosk приложение уходит из
   `downloading` в `idle` за ~100 с (3 попытки × 30 с «тишины» + паузы), а не за 9 минут.
3. Ручные проверки (только владелец, без автоматизации):
   - трей: меню «Открыть окно · Пауза микрофона · Настройки · Открыть папку конфига · Выход»;
   - `Ctrl+Alt+V` — окно появляется и сразу слушает;
   - крестик скрывает окно в трей, процесс жив; «Выход» из трея закрывает;
   - микрофон: «VoiceRunaCore, открой доту», «VoiceRunaCore, который час», barge-in словом VoiceRunaCore;
   - голос: переключение голоса и «Прослушать» в настройках;
   - автозапуск после перезагрузки (иконка в трее, окно не открывается).

## Ограничения среды (не баги кода)

- `api.open-meteo.com` недоступен из этой сети (геокодинг работает) — живой прогноз погоды проверить нельзя.
- `alphacephei.com` отдаёт модель wake word по ~0–160 Б/с: 46 МБ не скачиваются, приложение
  деградирует до хоткея (это штатный fallback по §5.1).
- Микрофона/аудиовыхода нет — wake word, STT и TTS проверены только юнит-тестами с фейками.

## Правила работы с владельцем

- **Никакого UI Automation, эмуляции кликов, SendKeys и перехвата фокуса** — это ломает управление
  мышью в его сессии. Интерфейс проверяем логами, скриншотами (пассивно) и API-тестами;
  ручные шаги владелец делает сам по текстовой просьбе.
- Каждое изменение — отдельный коммит `<тип>: <что>` и push в `main`.
