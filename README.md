# VoiceRunaCore — голосовой ассистент для Windows

**VoiceRunaCore** — локальный голосовой ассистент для Windows 10/11. Живёт в трее, слушает микрофон,
просыпается по выбранному слову (по умолчанию **«вокс»**) или по горячей клавише **Ctrl+Alt+V**, отвечает голосом,
запускает программы, открывает папки и файлы, подсказывает время и погоду, а на сложные
вопросы отвечает через LLM.

> Релиз **Beta v1.0**. Приложение работает локально: микрофон, распознавание речи, синтез
> голоса и инструменты — на вашем компьютере; в интернет уходят только запросы к LLM и погоде.

---

## Возможности

- **Слух.** Захват микрофона, нейросетевой VAD (Silero), распознавание речи faster-whisper
  (CPU, int8) с жёсткими фильтрами против галлюцинаций на шуме и тишине.
- **Имя и слово-будильник.** Имя ассистента задаётся в настройках и используется как слово-будильник;
  работает без отдельной модели ключевых слов: фраза распознаётся целиком, имя ищется в тексте.
  По умолчанию — «вокс» (варианты «вокс/вокса/вок/вос/vox»). Есть и режим Vosk KWS.
- **Мозги.** Быстрый Router: команды вроде «открой блокнот», «который час» выполняются сразу,
  без обращения к сети. Остальное уходит в LLM (DeepSeek/OpenRouter, OpenAI-совместимые API).
- **Руки.** Семь инструментов: `launch_application`, `open_folder`, `open_file`,
  `get_time`, `get_weather`, `set_volume` (громкость) и `create_file`
  (создание .txt/.md в `%USERPROFILE%\Documents\VoiceRunaCore`). Новые инструменты регистрируются
  через ToolRegistry.
- **Голос.** Локальный нейроголос Piper (офлайн), резерв — edge-tts и системный SAPI.
  Можно подкладывать свои голоса Piper в папку без пересборки.
- **Адаптивный микрофон.** Автоматическая калибровка шума при старте и кнопка
  «Калибровка микрофона»: пороги подстраиваются под любое устройство ввода.
- **Интерфейс.** Окно с историей диалога, индикатором состояния, редактором настроек
  (Звук, Голос, Модели, Программы, Прочее), трей, автозапуск, один экземпляр.

## Установка

### Вариант 1. Готовый установщик

1. Скачайте `VoiceRunaCore_x.y.z_x64-setup.exe` из раздела **Releases**.
2. Запустите установщик, приложение появится в меню «Пуск».
3. При первом запуске скачаются модели (распознавание речи, VAD, локальный голос) —
   нужен интернет, около 600 МБ. Прогресс виден в окне.
4. Настройки → **Звук**: выберите микрофон и нажмите **«Калибровка микрофона»**,
   затем 3 секунды помолчите.

### Вариант 2. Из исходников

```powershell
# 1. сайкар (Python 3.12)
cd sidecar
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt

# 2. интерфейс
cd ..\app
npm install
npm run build

# 3. приложение (Rust) — установщик в app/src-tauri/target/release/bundle/nsis
cd ..\packaging
powershell -ExecutionPolicy Bypass -File .\build-app.ps1
```

Сайдкар можно запустить и отдельно: `python -m voiceruna --port 8765` (токен — `VOX_TOKEN`).

## Настройка ключей API

Ключи хранятся **только** в `%APPDATA%\VoiceRunaCore\.env` и никогда не попадают в репозиторий.

1. Откройте приложение → **Настройки → Модели**.
2. Включите нужного провайдера и вставьте ключ в поле — он запишется в `.env`.
3. Нажмите **«Проверить ключ»**: должно появиться «Ключ работает».

Поддерживаются любые OpenAI-совместимые провайдеры. Пример `.env`:

```dotenv
DEEPSEEK_API_KEY=sk-...
OPENROUTER_API_KEY=sk-or-...
```

Можно задать вручную:

```powershell
notepad "$env:APPDATA\VoiceRunaCore\.env"
```

Если ключа нет, ассистент честно скажет: «не найден API ключ», а не «нет связи».
Порядок провайдеров и модели настраиваются на вкладке **Модели** (поле `priority`).

## Использование

- **Слово-будильник:** имя задаётся в «Настройки → Прочее → Имя ассистента» (по умолчанию «вокс»):
  скажите «вокс, открой блокнот», «вокс, который час».
- **Горячая клавиша:** `Ctrl+Alt+V` — слушать без слова VoiceRunaCore.
- **Кнопка микрофона** в окне — записать команду сразу.
- **Трей:** закрытие окна сворачивает приложение; меню позволяет включить/выключить микрофон.
- **Программы:** настройки → **Программы**; добавляйте путь (`%LOCALAPPDATA%\...`) или URI
  (`steam://rungameid/570`). Запустить можно только то, что есть в этом списке.

Конфигурация и данные лежат в `%APPDATA%\VoiceRunaCore`:

| Файл/папка | Назначение |
|---|---|
| `config.json` | настройки (устройства, пороги, провайдеры, фразы) |
| `.env` | ключи API (не коммитится) |
| `apps.json` | реестр программ и папок |
| `voices\` | сторонние голоса Piper (`*.onnx` + `*.onnx.json`) |
| `models\` | скачанные модели (Whisper, Silero, Piper, Vosk) |
| `logs\` | логи и отладочные записи `debug_mic.wav` |

## Диагностика

- Настройки → **Звук** → «Проверить микрофон» — уровень сигнала.
- «Записать 3 секунды и распознать» — весь путь STT с уверенностью и временем.
- «Калибровка микрофона» — измеряет шум и сохраняет пороги для выбранного устройства.
- «Диагностика» — модель STT, VAD, частота микрофона, что слышал wake-детектор.
- Логи: `%APPDATA%\VoiceRunaCore\logs\sidecar.log`.

Если ассистент «не слышит»: проверьте устройство ввода, поднимите громкость микрофона
в Windows и повторите калибровку в тишине.

## Ограничения Beta

- Погода работает через Open-Meteo с резервным источником wttr.in; в некоторых сетях
  провайдер погоды недоступен.
- LLM требует ключ и интернет; офлайн-режим отвечает только инструментами.
- Голоса Piper, кроме встроенной `ru_RU-irina`, подкладываются вручную.
